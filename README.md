### `~/ api --design`

```http
GET     /api/v1/orders              200 OK
GET     /api/v1/orders/{id}         200 OK          404 Not Found
POST    /api/v1/orders              201 Created     422 Unprocessable
PUT     /api/v1/orders/{id}         200 OK          409 Conflict
DELETE  /api/v1/orders/{id}         204 No Content  403 Forbidden
```

<table width="100%">
<tr>
<td width="25%" valign="top"><sub><b>CONTRATO</b><br/><br/>Especificação antes da implementação. OpenAPI como fonte da verdade.</sub></td>
<td width="25%" valign="top"><sub><b>SEMÂNTICA</b><br/><br/>Verbo certo, status certo. O protocolo já diz o que aconteceu.</sub></td>
<td width="25%" valign="top"><sub><b>VERSÃO</b><br/><br/>Versionamento explícito. Quebrar cliente em produção não é opção.</sub></td>
<td width="25%" valign="top"><sub><b>ERRO</b><br/><br/>Resposta de erro padronizada, rastreável e sem vazar detalhe interno.</sub></td>
</tr>
